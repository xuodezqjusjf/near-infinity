## Overview

Near Infinity is an open-source tool for reading, editing, and exporting every resource type used by Baldur's Gate, Icewind Dale, and Planescape: Torment, enabling deep modding without external converters.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Near Infinity** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Resource Browser** | Tree-view navigator for all game resource files including scripts |
| **Script Decompiler** | Decompile and edit BCS trigger-action scripts with syntax highlighting |
| **Export & Import** | Round-trip import and export for bitmaps, sounds, and text resources |
| **Search & Replace** | Full-text search across all string references with batch replace |
